Implementácia (prípady použitia)

Use-Case je k dispozícii v docs/usecase_diagram.drawio(.png).

Nižšie je stručná dokumentácia k implementácii, ktorá mapuje PHP controllery na prípady použitia.

Autentifikácia a používatelia

  • App\Http\Controllers\AuthController – login, logout, me (/api/auth/login, /api/auth/logout, /api/auth/me).
  • App\Http\Controllers\PlayerController – CRUD hráčov, profil, úprava vlastného profilu (/api/players, /api/players/{id}, /api/profile).

Tímy

  • App\Http\Controllers\TeamController – CRUD tímov (/api/teams, /api/teams/{id}).
  • App\Http\Controllers\TeamMembersController – pridanie/odobratie člena, výpis členov a počtu, odchod člena (/api/teams/{id}/members, /api/teams/{id}/members/count, /api/teams/{id}/members/leave).

Turnaje (Events)

  • App\Http\Controllers\EventController – CRUD turnajov (/api/events, /api/events/{id}).
  • App\Http\Controllers\ParticipantsController – registrácia/odhlásenie hráčov alebo tímov, výpis účastníkov, výpočet bodov a umiestnenia (/api/events/{id}/participants, /api/events/{id}/participants/count, /api/events/{event_id}/participants/{participant_id}/points, /api/events/{id}/participants/placement).
  • App\Http\Controllers\EventMatchController – generovanie pavúka a správa zápasov, výpis všetkých zápasov, detail/úprava/mazanie zápasu (/api/events/{id}/matches, /api/matches/{id}, /api/events/{id}/matches/generate).

Štatistiky a filtre

  • App\Http\Controllers\StatisticsController – súhrnné metriky (/api/statistics).
  • App\Http\Controllers\Filters\PlayerFilter, TeamFilter, EventFilter – filtrované zoznamy pre frontend (/api/filters/players, /api/filters/teams, /api/filters/events).

Databáza

ERD schéma je k dispozícii v docs/erd_diagram.drawio(.png). Migračné skripty sú v database/migrations.

Inštalácia

  • Backend: Laravel (PHP 8.x), závislosti cez composer install, migrácie php artisan migrate --seed.
  • Frontend: Vite/React, závislosti cez npm install, build npm run build, dev npm run dev.
  • Konfigurácia: skopírujte .env.example na .env, nastavte DB prístup, spustite php artisan key:generate.
